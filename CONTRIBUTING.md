# Contributing & Collaboration Guidelines

Thank you for your interest in contributing to **pero1999ita.github.io**!

---

## Code of Conduct

Please maintain a professional, respectful, and collaborative environment across all issues, pull requests, and community discussions.

---

## How to Contribute

### 1. Reporting Bugs & Suggesting Improvements
- Search existing issues to ensure the issue hasn't already been reported.
- Open a detailed issue describing the expected vs. actual behavior, browser environment, and screenshots if applicable.

### 2. Pull Requests (PRs)
1. Fork the repository.
2. Create a feature branch:
   ```bash
   git checkout -b feat/your-feature-name
   ```
3. Implement your changes:
   - Keep styles aligned with the existing glassmorphic design system and CSS custom properties.
   - Maintain vanilla HTML5, CSS3, and JavaScript standards (no external frameworks unless discussed).
   - Ensure external links with `target="_blank"` include `rel="noopener noreferrer"`.
   - Avoid inline CSS styles.
4. Commit with clear, descriptive messages:
   ```bash
   git commit -m "feat: add responsive layout adjustment"
   ```
5. Push to your branch and submit a Pull Request to `main`.
